Device tree for OnePlus Nord CE4 Lite 5G
=========================================
# How to use?
**Clone the repo to device/oneplus/camry**
```
git clone https://github.com/diathequeen/android_device_oneplus_camry.git -b lineage-23.2 device/oneplus/camry
```
**To start a build**
```
source build/envsetup.sh
breakfast camry
brunch camry
```
